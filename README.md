A GitHub-compatible git forge in TypeScript (Node 22): git smart-HTTP (protocol v2/v0 fetch, ls-refs, receive-pack), REST API for repos, issues, pull requests and contents, GraphQL, and MCP tools — all backed by one shared in-memory store. Kit checks: 112/120 (git 30/30, repos 15/15, issues 15/15, pulls 20/20, protocol 5/5, graphql 13/20, mcp 14/15).

## Run it

```sh
MAKEFUN_SHOP_TOKEN=<token> node --experimental-strip-types main.ts
```

The server listens on `$PORT` and registers with `$MAKEFUN_ENV_URL` when set.
